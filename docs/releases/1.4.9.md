## NiuniuHub 维护版

基于 Gongsc/Theme-Glassmorphism 1.4.8，保留原项目 MIT 许可与版权声明。

- 修复延迟图表提示框直接插入监控名称的 HTML 注入问题。名称按纯文本显示，并增加安全回归测试。
- 将实际使用的图标随主题打包，禁用缺失图标的远程 CDN 回退。
- 默认关闭第三方访客 IP 查询，背景改为主题自带图片。
- 新增“联网更新汇率”选项，默认关闭。关闭时使用内置参考汇率和本地手动覆盖值，金额折算仅供估算。
- 独立主题标识 `niuniuhub-glass`，可与原版并存；主题仓库及更新来源指向本 fork。

主题仍与管理后台同源；这些改动不提供浏览器权限隔离。主动开启 IP 查询、联网汇率或自定义外部背景后，浏览器仍会访问相应第三方服务。

安装：将本 release 的 `theme.tar.gz` 上传到 Monitor 后台，再选择 NiuniuHub · Glassmorphism。保留原主题即可随时切回。
